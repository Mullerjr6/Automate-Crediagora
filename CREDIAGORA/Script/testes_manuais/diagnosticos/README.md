# Diagnósticos manuais

Scripts auxiliares para inspecionar planilhas durante uma investigação. Eles
não fazem parte das tarefas agendadas e não alteram os arquivos de produção.

- `_inspect_metas.py`: mostra estrutura e fórmulas da planilha de metas.
- `_inspect_rows.py`: mostra os valores calculados das linhas de metas.
